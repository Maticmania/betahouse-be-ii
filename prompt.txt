# Backend API: Property Search Endpoint

This document outlines the specification for the property search API endpoint.

## 1. Endpoint Definition

*   **URL:** `/property/search`
*   **Method:** `GET`

## 2. Request

The search is performed by sending a GET request with a set of query parameters to filter the results.

### Query Parameters

| Parameter        | Type             | Optional | Description                                                                                             | Example                    |
| ---------------- | ---------------- | -------- | ------------------------------------------------------------------------------------------------------- | -------------------------- |
| `city`           | `string`         | Yes      | The city to search in. Should be URL-encoded.                                                           | `ikeja`                    |
| `state`          | `string`         | Yes      | The state to search in. Should be URL-encoded.                                                          | `lagos`                    |
| `propertyType`   | `string`         | Yes      | The type of property to filter by. Can be one of the enum values from `Property['propertyType']`.        | `apartment`                |
| `bedrooms`       | `number`         | Yes      | The minimum number of bedrooms.                                                                         | `3`                        |
| `bathrooms`      | `number`         | Yes      | The minimum number of bathrooms.                                                                        | `2`                        |
| `minPrice`       | `number`         | Yes      | The minimum price of the property.                                                                      | `1000000`                  |
| `maxPrice`       | `number`         | Yes      | The maximum price of the property.                                                                      | `5000000`                  |
| `minLandSize`    | `string`         | Yes      | The minimum land size (e.g., "500sqm"). Backend should parse this.                                      | `500sqm`                   |
| `maxLandSize`    | `string`         | Yes      | The maximum land size.                                                                                  | `1000sqm`                  |
| `furnished`      | `boolean`        | Yes      | Filter for furnished properties.                                                                        | `true`                     |
| `serviced`       | `boolean`        | Yes      | Filter for serviced properties.                                                                         | `true`                     |
| `minParkingSpaces` | `number`       | Yes      | The minimum number of parking spaces.                                                                   | `2`                        |
| `maxParkingSpaces` | `number`       | Yes      | The maximum number of parking spaces.                                                                   | `4`                        |
| `amenities`      | `string[]`       | Yes      | A list of required amenities. Sent as multiple query parameters with the same key.                      | `amenities=pool&amenities=gym` |
| `sort`           | `string`         | Yes      | The sorting order for results. E.g., `price_asc`, `price_desc`, `newest`. Defaults to `newest`.           | `price_asc`                |
| `page`           | `number`         | Yes      | The page number for pagination. Defaults to `1`.                                                        | `2`                        |
| `limit`          | `number`         | Yes      | The number of results per page. Defaults to `10`.                                                       | `20`                       |

### Example Request

A GET request to the following URL:
`/property/search?state=lagos&city=ikeja&propertyType=apartment&bedrooms=3&minPrice=2000000&maxPrice=10000000&amenities=pool&amenities=gym&sort=price_asc&page=1&limit=12`

## 3. Response

### Success Response (200 OK)

The response will be a JSON object with the following structure:

```json
{
  "properties": [
    {
      "_id": "60d5ecb4b39b8d4f4e8b4567",
      "propertyId": "BH12345",
      "title": "Modern 3-Bedroom Apartment in Ikeja",
      "slug": "modern-3-bedroom-apartment-in-ikeja",
      "price": 5000000,
      "category": "rent",
      "propertyType": "apartment",
      "location": {
        "address": "123 Allen Avenue",
        "city": "Ikeja",
        "state": "Lagos",
        "lga": "Ikeja"
      },
      "bedrooms": 3,
      "bathrooms": 4,
      "toilets": 4,
      "parkingSpaces": 2,
      "furnished": true,
      "serviced": true,
      "images": [
        { "url": "https://example.com/image1.jpg", "publicId": "some_id_1" }
      ],
      "thumbnail": {
        "url": "https://example.com/thumb.jpg",
        "publicId": "some_thumb_id"
      },
      "agent": {
        "_id": "60d5ecb4b39b8d4f4e8b4568",
        "firstName": "John",
        "lastName": "Doe",
        "phone": "08012345678",
        "email": "john.doe@example.com"
      },
      "amenities": ["pool", "gym", "24hr security"]
    }
  ],
  "total": 25,
  "page": 1,
  "totalPages": 3,
  "hasNextPage": true,
  "hasPrevPage": false
}
```

*   `properties`: An array of `SearchPropertyResult` objects. The structure of these objects is defined in `types/search.ts`.
*   `total`: The total number of properties matching the query.
*   `page`: The current page number.
*   `totalPages`: The total number of pages available.
*   `hasNextPage`: A boolean indicating if there is a next page.
*   `hasPrevPage`: A boolean indicating if there is a previous page.

### Error Response

*   **400 Bad Request:** If the query parameters are invalid (e.g., non-numeric `minPrice`), the response should indicate the error.
*   **500 Internal Server Error:** If an unexpected error occurs on the server during the search.

**Example Error Response:**
```json
{
  "error": "Invalid value for 'minPrice'. Must be a number."
}
```
